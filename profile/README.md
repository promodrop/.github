# Promo Drop

[Promo Drop](https://promodrop.codes) is a free site and Chrome extension for people buying memberships, courses and communities on Whop. Every code we list is tested at Whop's checkout and shows the date it was last checked.

## Open data

- [whop-fees-dataset](https://github.com/promodrop/whop-fees-dataset): what a Whop sale costs in platform and payment fees, with a dated CSV and chart (CC BY 4.0).
